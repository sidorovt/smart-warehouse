# Информационная система интеллектуального управления складскими запасами с применением методов предиктивной аналитики.

## Участники проекта:
• PO/BA: Муранов Сергей<br>
• Backend: Курилкин Александр<br>
• Frontend: Семеняка Максим<br>
• Data/ML: Сидоров Тимофей<br>
• QA/DevOps: Набиев Эльтадж<br>

## Цель:
Разработать минимальную работающую версию системы, которая принимает исторические данные о продажах, выполняет их предобработку, прогнозирует спрос на 30 дней с помощью ML-модели и на основе текущих складских остатков определяет необходимость пополнения и рекомендуемый объём заказа. Результаты представлены менеджеру в веб-интерфейсе в виде текущих остатков, прогноза спроса, предупреждений о риске out-of-stock и рекомендаций по заказу.
